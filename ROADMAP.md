# Spring by Example V2 Roadmap

Spring by Example V2 explores the broader Spring ecosystem through **small but extensive examples**.

### Guiding Principle

> **Small examples, extensive coverage.**

Examples should be focused enough to understand individually while collectively covering the important concepts of each technology.

- ⬜ Spring Data

## Completion Criteria

A module is considered complete when:

- Planned examples are implemented.
- Important concepts are covered.
- Examples are runnable.
- Tests are included where appropriate.
- Documentation explains the concepts.
- The module README is complete.
- The module builds successfully.
- Main README progress is updated.
